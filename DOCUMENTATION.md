# The Kriwils: Comprehensive Project Documentation

Welcome! This document explains exactly how **The Kriwils** (an AI-powered quiz platform) works, from the code on your laptop to the AI in the cloud.

---

## 1. The Big Picture (How it works)
Imagine The Kriwils as a bridge between three main "islands":
1.  **Your Laptop (The Frontend)**: What the user sees in their browser.
2.  **Supabase (The Database)**: Where all the user accounts, quizzes, and scores are stored.
3.  **Gemini AI (The Brain)**: The artificial intelligence that reads your topics or PDFs and writes the questions.

When a user clicks "Generate," your laptop asks the AI for questions, the AI sends them back, and your laptop saves them into Supabase.

---

## 2. The Tech Stack (The Tools We Used)
*   **HTML/CSS**: The skeleton (structure) and the skin (styling) of the website.
*   **JavaScript (Vanilla)**: The muscles. It handles all the logic without needing complex frameworks like React.
*   **Node.js**: The heart. It runs a simple server (`server.js`) that delivers the files to your browser.
*   **Supabase**: The memory. It handles the "Login/Register" system and the database tables.
*   **Gemini 2.0 Flash**: The intelligence. A fast, low-cost AI model from Google that generates the quizzes.
*   **PM2**: The bodyguard. It makes sure your server stays running 24/7, even if it crashes or the computer restarts.
*   **Cloudflare Tunnel**: The tunnel. It allows people on the internet to visit your local computer safely.

## 3. Folder & File Structure
*   `server.js`: The entry point. It tells the computer "Listen on port 6767 and send the HTML files when someone visits."
*   `public/`: This folder contains everything the user's browser can see.
    *   `index.html`: The home page (where you generate quizzes).
    *   `quizzes.html`: The "Manager" page where you see, edit, or delete your quizzes.
    *   `play.html`: The "Player" page where people actually take the quiz.

    *   `js/quizzes.js`: The logic for managing your list of quizzes and stats.
    *   `js/play.js`: The logic for the game (timers, scoring, confetti, and saving results).
    *   `css/style.css`: All the visual designs, animations, and layouts.

## 4. Core Features Explained

### **A. AI Quiz Generation**
In `script.js`, when you click generate, the code:
1.  Reads the text from your PDF (if uploaded).
2.  Sends a "Prompt" (instructions) to Gemini AI.
3.  The AI is told to return **JSON** (a format computers love).
4.  The code parses that JSON and saves it to the `quizzes` table in Supabase.

### **B. Pretty URLs (The /play/ABC123 magic)**
Normally, a URL looks like `play.html?id=123-456`. That's ugly.
1.  We generate a random 6-character **Short Code** (like `KRIWIL`).
2.  In `server.js`, we told the server: "If someone goes to `/play/KRIWIL`, don't give them an error. Instead, secretly show them `play.html`."
3.  The `play.js` code then looks at the URL, sees `KRIWIL`, and asks Supabase: "Which quiz belongs to this code?"

### **C. Toast Notifications**
Instead of the ugly browser popups (`alert()`), we built a custom system in `auth.js`.
*   It creates a beautiful box in the corner.
*   It automatically changes size based on the message.
*   It disappears on its own after 4 seconds.

## 5. Security & Safety
*   **Passwords**: These are never seen by you or stored as text. Supabase "hashes" them using Bcrypt. They are mathematically locked.
*   **API Keys**: Your Gemini Key and Supabase Key are restricted. They allow the website to work but don't give anyone full control of your accounts.
*   **Cloudflare**: You don't "open" your router. You create a secure, outbound tunnel. This hides your home IP address from hackers.

## 6. How to Update the Site
If you are developing on your laptop and want the VM (the live site) to update:
1.  **Laptop**: `git add .` -> `git commit` -> `git push`.
2.  **VM**: `git pull` -> `pm2 restart all`.
3.  **Browser**: Hard Refresh (`Ctrl + F5`) to clear old files.

## 7. Troubleshooting
*   **Site is down?** Check if PM2 is running (`pm2 status`).
*   **AI is failing?** Check your Gemini API Key or your internet connection.
*   **Changes not showing?** It's almost always the **Browser Cache**. Clear it!
